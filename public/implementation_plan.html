1. Executive Summary

This plan outlines the integration of the 6-phase Printing & Packaging ERP workflow into the active Laravel project (jmd_sol_laravel). The roadmap implements detailed tracking, validation gates, and revision handling without disrupting existing API services or the mobile app.

Mobile App API Compatibility: Database tables custom_projects, production_orders, and sample_orders are actively in use by a mobile application. All new columns must be nullable or have default values. No existing columns should be renamed or deleted.
Staged Changes: An invoice creation and sending layout (with billing_address, shipping_address, payment_status, and signature migrations/views) is currently staged in git. Let us know if we should commit this first.

2. Core ERP Modules

The system adds three critical custom modules to handle complex business rules, revisions, and quality control checks.

Centralized Approval Workflow

A centralized model (CrmApproval) tracks transitions. Each approval step (Sales review, Customer decision, Proof approval, Color match, Balance payment check) is logged with authorization details and feedback.

Field Name Type Description
approvable_type string Polymorphic model type (e.g. CrmEmail, CustomProject)
approvable_id unsignedBigInteger Polymorphic model ID
stage string Workflow step (e.g. sales_agent_review, proof_review)
status string State (pending, approved, rejected, revision_requested)
approver_id unsignedBigInteger ID of user/agent or customer identifier

Design Proof Revisions Tracking

Instead of overwriting files, this module logs historical proofs (v1, v2, v3) under ProofRevision, tracking files along with customer feedback notes when revision requests are logged.

Field Name Type Description
custom_project_id unsignedBigInteger Linked project foreign key
version_number integer Auto-incrementing version count (1, 2, 3...)
file_path string Path to file asset on disk/storage
feedback_notes text Customer feedback input detailing changes requested

QC (Quality Control) Module

Before any shipment labels can be generated, a QC inspector must complete a checklist. If any of the 6 checks fail, the order is blocked.

  • Dimension Check: Verify physical sizing against specifications.
  • Fold Color Check: Verify alignment and folding color accuracy.
  • Quantity Check: Verify final physical sheet counts.
  • Glue Strength Check: Ensure gluing passes strength tests.
  • Barcode Scan: Scan barcode to verify correct labels.
  • Packaging Inspection: Confirm final palletization standards.
